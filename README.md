# math_problems

Авторские олимпиадные задачи по математике с решениями (на русском языке).
*Olympiad-style math problems with solutions (in Russian).*

Полный список условий — в файле [Problems_PR.pdf](Problems_PR.pdf).

## Задачи

| № | Тема | Условие (кратко) | Решение |
|---|------|------------------|---------|
| 0 | Геометрия / комбинаторика | Расположить семь точек так, чтобы вписанных четырёхугольников с вершинами в них было втрое больше, чем описанных, причём их число было наибольшим возможным. | [Problem_0_PR.pdf](Problem_0_PR.pdf) |
| 1 | Алгебра | Известно, что `xy + 3 = 2x + 2y`. Доказать, что `\|\|x\| + \|y\| + x + y − 4\| ≤ 1` или `\|\|x − 4\| + \|y − 4\| − x − y + 4\| ≤ 1`. | [Problem_1_PR.pdf](Problem_1_PR.pdf) |
| 2 | Геометрия | Параллелограмм `ABCD` с `BC = BD`; доказать факт о пересечении заданной окружности и прямой. | [Geom_PR.pdf](Geom_PR.pdf) |
| 3 | Комбинаторика | Садоводы и шлагбаумы: при каких `n` из диагоналей прямоугольников `1×2, 2×3, …, n×(n+1)` можно составить замкнутую несамопересекающуюся ограду? | [SNT_PR.pdf](SNT_PR.pdf) |
| 4 | Шахматная комбинаторика | «Вихревой турбинатор» бьёт клетки спирали. Сколько их можно поставить на доску 8×8, чтобы никто никого не бил? | [Vikhrevoy_Turbinator_PR.pdf](Vikhrevoy_Turbinator_PR.pdf) |
| 5 | Теория чисел | К числу `n` на каждом шаге прибавляются остатки от деления на его ненулевые цифры. Доказать, что существует константа `C`, такая что число всегда меньше `nC`. | [Burlakov_Totmakov_Theorem.pdf](Burlakov_Totmakov_Theorem.pdf) |

### Дополнительная задача

Найти наибольшее натуральное число, у которого количество букв в его словесной записи по-русски равно сумме его цифр. — [Extra_Problem.pdf](Extra_Problem.pdf)
